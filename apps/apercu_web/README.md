# apps/apercu_web

Mini-app Flutter web qui joue un exercice avec le même package `moteur_exercices` que l'app mobile.
Elle servira d'aperçu dans le back-office (chargement d'un JSON par fichier ou `postMessage`).

Lancer : `flutter run -d chrome` depuis ce dossier, après `flutter pub get` à la racine du dépôt.
Construire : `flutter build web --release`.
