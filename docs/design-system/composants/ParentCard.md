# ParentCard

Carte de l'espace parent : titre, période, indicateurs chiffrés.

- Police `latin` en français, arabe sans harakat dans l'espace parent (décision 27). Fond `surface`, indicateurs sur `screen`.
- Chiffres en `font-variant-numeric: tabular-nums`. Couleurs de maîtrise : `olive` 80 % et plus, `amber` 60 à 79 %, `coral` sous 60 %, toujours avec la valeur écrite.
