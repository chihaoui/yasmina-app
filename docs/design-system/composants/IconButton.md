# IconButton

Bouton carré ou rond pour une action sans libellé : retour, quitter, réécouter la consigne. Variante large `listen` avec le mot « اِسْمَعْ » pour faire entendre un mot.

- **Le consommateur fournit** : l'icône et un libellé d'accessibilité dans la langue de l'interface.
- Taille au moins `target-min`, fond `tile` ou `surface`, bordure `line`. La réécoute est ronde (`radius-pill`) avec l'icône en `blue`.
- La flèche de retour suit le sens d'écriture (miroir en arabe).
