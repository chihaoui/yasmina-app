# MapNode

Une étape sur la carte du trimestre : la lettre (ou 🏆 pour le défi de l'unité) dans un rond de 74 px.

- États : ouverte (`sun`, pulsation), terminée (`node-done` et étoiles `amber`), verrouillée (`line`, texte `muted`, cadenas), à venir (pointillé `path`). Le défi est un carré arrondi.
- Relief `shadow-node`. Fond de carte `map`. Le chemin serpente selon le sens d'écriture.
